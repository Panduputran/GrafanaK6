## Deskripsi

**GrafanaK6 CLI** adalah *framework* pengujian beban (*load testing*) berbasis CLI interaktif yang dirancang untuk mempermudah eksekusi skenario pengujian performa API dan aplikasi web. Dengan CLI ini, kamu tidak perlu mengetikkan perintah `k6 run` yang panjang secara manual di terminal, melainkan cukup memilih *environment*, tipe tes, dan skenario melalui antarmuka terminal interaktif.
