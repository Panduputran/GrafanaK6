## Overview

**GrafanaK6 CLI** is an interactive, terminal-based load testing framework designed to streamline performance testing workflows for web applications and APIs. It abstracts complex `k6 run` CLI commands into a menu-driven interface, allowing developers to execute modular test scenarios across multiple environments with automated result exports.
